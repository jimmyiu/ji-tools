# JI TOOLS

This is a playground for experiencing harness engineering.

## Development setup

Requires [fnm](https://github.com/Schniz/fnm) with `--use-on-cd`. `.node-version` pins Node 26; `package.json` pins pnpm 12.9.1. Node 25+ no longer bundles corepack, so install pnpm with npm instead.

From the repo root:

```sh
fnm install && fnm use
npm install -g pnpm@12.9.1
pnpm install
```
