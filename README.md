# JI TOOLS

This is a playground for experiencing harness engineering.

## Development setup

Requires [fnm](https://github.com/Schniz/fnm) with `--use-on-cd`. From the repo root: `fnm install && fnm use && corepack enable && pnpm install`. `.node-version` pins Node 26; `package.json` pins pnpm 10.8.1.
